# v0.2.0 — Host Dashboard

- **State:** Complete
- **Depends on:** v0.1.0

## Outcome

The owner can open a simple, unelevated dashboard and immediately understand this computer's prerequisites, folder readiness, local-access readiness, Tailscale readiness, and current hosting state.

## In scope

- Run the diagnostic on launch and provide a clear Refresh action.
- Show computer, managed-folder candidate, local-network, and Tailscale status at a glance.
- Report local and Tailscale readiness independently; either path may be ready by itself.
- Show that Balls Server hosting is not configured yet.
- Keep technical evidence available behind expandable details.
- Treat future administrator approval as information, not a readiness requirement.
- Require SMB 3.0 or newer and treat enabled SMB1 as Action required.
- Use the canonical prerequisite and overall readiness terms from `CONTEXT.md`.

## Out of scope

- Detecting or taking ownership of existing Windows shares.
- Creating shares, accounts, permissions, firewall rules, mappings, or dependencies.
- Setup, repair, pairing, background monitoring, installation, or elevation.
