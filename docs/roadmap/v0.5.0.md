# v0.5.0 — Pilot reliability and diagnostics

- **State:** Proposed
- **Depends on:** v0.4.0

## Outcome

The first working share remains understandable and recoverable across common host, client, credential, name-resolution, sleep, and network failures.

## In scope

- Harden the v0.4.0 host and client workflows from real two-computer pilot evidence.
- Show client computer state, host identity, selected access path, reachability, SMB compatibility, credential state, and mapping state.
- Keep local and Tailscale path results distinct and reject public endpoints.
- Attempt authentication at most once per explicit user action to avoid account lockout.
- Add focused retry, reconnect, and recovery actions with plain explanations.

## Out of scope

- Multiple clients, guest access, public endpoints, automatic background retries, or general remote configuration.
