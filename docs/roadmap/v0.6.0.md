# v0.6.0 — Multiple access grants and path changes

- **State:** Proposed
- **Depends on:** v0.5.0

## Outcome

An owner can grant and revoke access independently for multiple client Windows profiles, and each client can explicitly change between approved LAN and Tailscale endpoints.

## In scope

- Create a separate limited identity and setup code for each access grant.
- List, label, rotate, and revoke grants independently without affecting other clients.
- Change one client explicitly between its approved LAN and Tailscale endpoints.
- Preserve credential-storage consent, persistent mapping, and retry-safety guarantees from v0.4.0/v0.5.0.

## Out of scope

- Shared credentials between clients, owner Microsoft/Windows password collection, Windows Hello as an SMB password, guest access, public routes, or silent path fallback.
