# v0.7.0 — Verification, repair, and removal

- **State:** Proposed
- **Depends on:** v0.6.0

## Outcome

Owners can verify end-to-end access, repair product-owned drift, revoke one client's access, remove hosting configuration, or forget a client connection without harming unrelated configuration or files.

## In scope

- Host connection list with friendly label, access state, and last successful connection when safely available.
- Revoke or rotate one access grant without affecting other clients.
- Repair only settings recorded as product-owned.
- Remove the managed share, access identities, product-owned permissions/firewall changes, saved credential, and mapping as selected.
- Preserve the managed folder and every file in it under all removal and uninstall paths.
- End-to-end temporary-file verification over isolated LAN and test-tailnet paths.
