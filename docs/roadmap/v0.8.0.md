# v0.8.0 — Installer, signing, and updates

- **State:** Proposed
- **Depends on:** v0.7.0

## Outcome

Balls Server has an implementable and tested distribution system for signed installation, upgrade, repair, removal, and user-controlled updates without merging installer privileges into the dashboard.

## In scope

- Select and document installer, code-signing, distribution, and update technologies.
- Keep the unelevated dashboard, privileged setup helper, and installer as distinct trust responsibilities.
- Implement clean install, in-place upgrade, application repair, and application removal.
- Preserve hosted data and require explicit handling of remaining hosting configuration.
- Verify signed artifact provenance and present update information before installation.
- Keep updates user-controlled; no silent installation in v1.0.
