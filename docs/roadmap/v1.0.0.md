# v1.0.0 — Official file-sharing release

- **State:** Proposed
- **Depends on:** v0.9.0

## Outcome

The first official Balls Server release lets an owner configure one authenticated read/write folder and lets approved Windows clients map it safely over a private LAN or Tailscale.

## Release boundary

- One managed folder per host.
- Independent local and Tailscale readiness.
- Authenticated SMB 3.0+ with SMB1 disabled and signing preserved.
- Dedicated, revocable access grant per client Windows profile.
- Unelevated dashboards plus narrowly scoped, consent-driven privileged setup.
- Verification, repair, removal, and data-preserving uninstall behavior.
- Local-only diagnostics with explicit-preview export; no required cloud account or telemetry.
