# v0.3.0 disposable VM verification topology

Status: design and executable validation evidence for Ticket 08. This contract authorizes no VM, Hyper-V, SMB, account, credential, filesystem, network, or Windows mutation. It is the later adapter boundary, not a VM-run claim.

## Suite boundary and guard

The default suite remains `dotnet test`: unelevated, offline, deterministic, and non-mutating. It has no dependency on Tailscale, Hyper-V, shares, accounts, mappings, credentials, or a second computer.

The separate future mutation runner is opt-in only. It must deny before obtaining an adapter unless all of these exact inputs are true:

| Guard input | Exact rule |
| --- | --- |
| Elevation | A real elevated administrator token is present. |
| Disposable marker | The VM has the exact non-production marker `BallsServer.DisposableVm`. |
| Snapshot | Current snapshot ID equals the known `v030-configured` ID supplied by the manifest. |
| Namespace | Every new object begins with one unique `BallsServer.Test.<run-id>` namespace. |
| Scope proof | Fixture folder, account, credential target, mapping, and tailnet identity all begin with that exact namespace; the fixed share is exactly `Balls`. Any other share, production object, or unproven object denies. |

Eligibility is only a plan decision. It does not create a VM or invoke a native adapter. The development host and default execution therefore deny.

## Supported topology

Use supported, disposable Windows 11 Pro VMs only. The host and client each have a private/internal virtual NIC; the two-VM LAN has no external virtual switch, public address, cloud firewall, router forwarding, or public/external SMB route.

```text
Host VM  <--- private/internal LAN, TCP 445 only --->  Client VM
   ^                                                        |
   | optional private non-production tailnet, TCP 445 only  |
   +--------------------------------------------------------+
```

The optional tailnet leg is separately selected, uses non-production identities, and allows only client-to-host TCP 445. It is not a fallback, does not obtain Tailscale credentials, and never makes the local route public.

## Snapshots, fixtures, inventories, interruption, and reset

| Snapshot ID | State | Exact purpose |
| --- | --- | --- |
| `v030-clean` | Clean | Supported Windows with no product state. |
| `v030-tailscale-ready` | Tailscale-ready | Private non-production tailnet signed in, with no product state. |
| `v030-configured` | Configured | Product-test-only fixture state and the only mutation-suite restore point. |

Each run assigns one namespace and creates only its fixture folder, grant account, share, credential target, mapping, verification file, firewall identities, and ledger records. Before and after inventories contain only the namespace, opaque stable-ID/fingerprint fields, snapshot ID, selected path, assertion outcomes, cleanup decision, and redacted evidence reference. They exclude secret values, raw ACLs, private names/paths, UNC roots, addresses, tailnet identities, and file listings.

The primitive interruption set is: before durable intent; after durable intent; after native primitive before verification; after verification before ledger commit; and after ledger commit. Test one selected primitive at a time and restore before the next point. The expected result is the applicable rollback, Repair needed, Unknown, or manual-recovery path from the operation contract; a crash never authorizes a retry or broad cleanup.

The evidence envelope is a closed non-secret record: `runId`, `snapshotId`, `topologyLeg`, `operationId`, `scenario`, `phase`, redacted before/after inventories, assertion IDs, typed result, rollback/recovery decision, restore/discard result, and bounded native code. A failing, interrupted, or inconclusive run restores the exact baseline or discards the VM. A passing run also restores/discards it. No run may continue from altered state.

## Required end-to-end rows and assertions

| Row | Required condition and proof |
| --- | --- |
| LAN | Exact selected private-LAN endpoint succeeds with authenticated SMB only. |
| Full MagicDNS | Exact selected full MagicDNS endpoint succeeds only on the private tailnet leg. |
| Selected-path failure | The selected path fails without alias, IP, alternate path, or automatic fallback. |
| Explicit switch | Imported, bound endpoint update is required; prior mapping/target survives refusal. |
| Rename/collision drift | Rename and unmanaged collision stop in drift/refusal with no adoption. |
| Reconnect | Exact saved current-user target and selected reconnect choice persist only as recorded. |
| Credential collision | Existing different/unmanaged target stops before authentication. |
| One-attempt failure | One exact authentication attempt produces a typed non-oracular result and no retry. |
| Rotate | Exact grant rotates once, remains disabled pending separate authorized activation. |
| Revoke | Exact grant loses access; no unrelated group, session, or client cleanup is touched. |
| Open-file removal | Attributable open work blocks narrow removal and preserves the managed folder/files. |
| Leftover verification file | Only the unique owned verification file is retained privately for narrow cleanup. |
| Ledger loss/corruption | Primary/mirror rules produce protected-state repair, Unknown, or read-only total-loss recovery. |
| Reboot | Re-observation reconciles only exact owned state and never repeats an applied primitive. |
| Host/client cleanup | Exact host and current-user client cleanup reach proven-owned absence while retaining user files. |

Every row asserts SMB 3.0 or later, SMB1 disabled, signing preserved, a private route, share-and-NTFS intersection, per-grant isolation, exact mapping and credential targets, ownership reconciliation, unrelated-state preservation, and managed-folder/file survival. A test may report `NotRun` only before the native adapter exists; this v0.3 deliverable records no mutating VM execution.
